# 四区域候选的等成本强对照与立论修正

2026-10-27。真实局部探针尚未启动，原协议、元数据选择和门保持。此项数学/合成检查
在观察真实新动作得分之前发现原先“先预测避免K次解码”立论缺少一个更强对照。
它不撤销原控制实验；它收紧通过探针之后的拟合准入解释。

## 一次全部动作已经包含所有单动作

固定同一输入、参考、模型与残差。四个动作的传播支持S_i两两不相交，且已证明其联合
输出等于按这些支持拼合单动作输出。记无动作logits为z0，全部动作输出为zAll，则
单动作输出可直接恢复：`z_i = where(S_i, zAll, z0)`。
任意子集J同理：`z_J = where(union(S_i for i in J), zAll, z0)`。
这些都是由可组合性直接推出的结果，不能再把每个单动作一次完整解码当最强成本下界。

明确CPU合成原ResNet18/FPN64/GN8检查在
`runs/local_composition_equal_cost_control_20261027`：seed20261027，2×256输入，固定非零
随机adapter最后层std0.01，四个原探针框。实际执行全部动作、四个单动作与15个子集，
均与从zAll恢复的输出bit-exact；各单动作有12167或12168个非零logit变化，非空检查。
这是21次验证性decoder调用（含baseline），不是部署成本测量，也不是实数据结果。

| 部署策略 | 当前稠密实现decoder调用 | 选择时可用信息 |
| --- | --- | --- |
| 基准→先预测动作代价→一次选择后的联合动作 | 2 | 基准features/logits、固定残差，尚未执行的动作由模型预测 |
| 基准→一次全部互不相交动作→选择输出区域 | 2 | 前者信息，以及实际动作logits和已知预测翻转区域 |
| 基准→逐动作原GN完整解码→拼合 | 1+所选动作数 | 依所执行动作而定；仍保留为原GN效果对照 |

第二行在本稠密实现没有更多decoder调用，且增加实际动作信息。是否选择“无动作”
不改变已发生的计算。encoder/adapter、缓存、selector、拼合和实际墙钟也必须计入，
不能只比较decoder的次数。只有另有经过匹配实测的稀疏执行、早停或重叠互斥动作设定，
先预测才可能带来不同成本；当前都未实现/准入，不为挽救主张自动加入这些模块。

因此撤回当前四区域稠密方案相对最强对照的“避免K次解码”“O(K)生成联合标签为专属
收益”等论据；从一次全部动作及真值可得到同一空间下的所有子集标签。归一化/缓存
本已是已有组件。当前真实探针仍有价值：检查真实FP16可组合性与固定局部动作的理想
收益，决定该动作空间是否值得继续研究；它不能单独验证先预测方案的贡献。

## 计数预测与选择不能自动带来新算法

标签固定时`deltaFN=-deltaTP`、`deltaTN=-deltaFP`，净混淆增量只有两个自由度；gross
转移仍用于区分新增伤害和相互抵消。多个预测头本身不增加新信息。

对于单一pooled F1目标，固定分数参数lambda后，分式规划的动作增量为
`2*deltaTP - lambda*(2*deltaTP+deltaFP+deltaFN)`，即
`(2-lambda)*deltaTP - lambda*deltaFP`。若只有同成本基数预算，选择就是正收益top-k；
有共享伤害/异质成本约束时是普通有限集/背包问题，必须有相同预测代价的通用控制。
不能把通用分数优化改名为联合选择创新。45条件的mean-F1是45个分别pooled的分数均值，
也不能用一个汇总lambda或pool全部条件偷偷代替。

若使用预测计数，`F1(E[counts])`只是plug-in目标，不自动等于`E[F1(counts)]`，更不能
由真实计数上的精确可加性宣称预测风险有保证。要计算单样本plug-in F1，还需要基准
计数的估计；部署时基准TP/FP/FN不是免费可知。原无动作logits不是其真值计数。

一个按本项目零分母F1=0约定的精确反例：三像素真值以0.6/0.4概率分别为000/011；
动作A预测001、B预测111。期望F1分别为4/15与8/25，B更高；期望计数的F1分别为
4/9与8/19，A更高。每个可能世界中两动作用同一真值，存在严格排序反转。
枚举结果保存在同目录expected_count_F1_counterexample.json；这是数学反例，不是
数据实验，也不否定预测计数可以有经验价值，只排除自动的最优性/风险保证。

## 后续决策

若冻结探针失败，按其原停止门关闭固定四区域动作，不改区域、门或样本追分。
若通过，`next_fitting_resource_gate`仅表示动作空间余量，**不得自动训练先预测头**。
先将“一次全部动作后选择”纳入同容量/同数据/完整计算成本比较，并说明剩余的可证伪
贡献。可研究普通局部监督与实际动作错误代价目标，但不得把既有whole-tile失败隐去、
把标签知情上界当收益或把学习器/输入/选择目标同时改变后归因给其中一个。
新颖性与任务效果仍未成立，论文尚不具备投稿证据。
