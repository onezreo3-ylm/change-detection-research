# 创新性与撞车风险复核

检索日期：2026-09-11。对象：附件中的 PSE + PCDC + CPC 方案。
本报告区分公开证据、研究判断与尚未验证的假设，不把附件自称的“创新”作为证据。

## 结论：有条件推进基线，不宜按“三个独立创新点”直接写论文

在本次可检索的一手公开资料中，未确认与整套方案完全同构的工作；这不等于
不存在，也不能覆盖尚未公开投稿。更实质的风险是：退化估计、条件专家路由、
空间校正和扰动一致性分别已有充分近邻，简单组合有较高的增量创新风险。

研究问题仍有实验价值。可争取的差异不是“加入 MoE”，而是：在受控的双时相
非语义扰动下，用预测的局部扰动状态进行任务相关特征校正，并证明伪变化减少
不是以真实变化召回下降为代价。该差异目前仍需实验证明，不能预先宣布成立。

我的定性判断：完整同构撞车尚未确认；模块层面的重合风险高；任务层面的相邻
工作风险中高；作为硕士论文方向可以先做低成本基线与证伪实验。不提供没有
统计依据的“撞车概率”或发表保证。

| --- | --- | --- |
| [CSD-Net](https://www.mdpi.com/2072-4292/18/13/2074)，2026-06-24 | 用伪变化 token 估计全局风格代理，在特征中减去辐射偏差；基础检测器不依赖其可选大模型精炼阶段 | “显式去除非语义特征影响”已不是空白。局部多退化路由和变化保留必须成为可验证差异，不能因其可选 MLLM/SAM 就忽略基础模型 |

| [Revisiting Consistency Regularization / SemiCD](https://arxiv.org/abs/2204.08454)，首版 2022-04-18 | 在双时相深层差分上扰动，约束变化预测一致性 | CPC 若只是 clean/perturbed 输出一致或差分 L1，创新性偏弱 |
| [GTPC-SSCD](https://arxiv.org/abs/2411.18880)，首版 2024-11-28；页面注明 ICME 2025 接收 | 图像级强弱一致性、特征级扰动一致性和样本难度门控 | “多层扰动＋门控＋一致性”在变化检测中已有近邻；半监督与全监督不同，但不能以此跳过比较 |
| [SII](https://www.mdpi.com/2227-7390/12/22/3577)，2024-11-15 | 明确讨论一致性正则可能遗漏细微真实变化，并以样本构造缓解 | “抑制扰动不能抹除变化”的动机本身也已有表述，需给出不同机制及直接证据 |

## 提交论文前必须补足的区分证据

1. **强增广对照**：同骨干、同初始化、同样本/扰动、同优化预算，比较 clean、
   augmentation-only、augmentation + ordinary consistency。
2. **路由必要性**：参数量/计算量可比的普通 adapter、单专家、静态多专家、
   无显式 PSE 的条件门控、完整 PCDC。不能把容量增加等同于条件建模收益。
3. **变化保留**：同时记录变化区 Recall/漏检、未变化区误报率、clean F1 和
   corruption mF1；仅降低 Delta-F1 可能来自降低 clean F1。
4. **干预式检查**：干净输入不应强校正；局部扰动不应使远处真变化消失；交换
   A/B 后结果应稳定。报告错误路由、过度校正和失败案例。
5. **PSE 独立评价**：严重度 MAE、局部 mask 指标、路由统计；测试时不输入真实
   扰动元数据。单列 oracle 条件，严禁混入主结果。
6. **冻结评测协议**：训练与测试随机数流分离；固定样本、扰动参数、五档强度
   及组合顺序。LOGO 中留出的整组不能进入训练、调参或选择 checkpoint。
7. **统计稳定性**：至少多个独立训练种子，报告均值/方差；区间按原始影像对
   重采样，避免把相关切片当独立样本。合成结果不足以声称真实成像鲁棒性。

## 附件中应先澄清、但本轮不实现的技术问题

- **Identity 公式**：残差专家 E0 必须输出 0 才能表示“不校正”；若输出 F，
  则 `F + M*w0*F` 会缩放特征。应保留零残差旁路，不是直接套 nn.Identity。
- **签名可辨识性**：三个 [0,1] 分组数无法自然表示亮/暗方向，噪声/模糊/JPEG
  也并非同一校正。先检验表示是否足够，而不是预设其能解释复合扰动。
- **空间监督的含义**：注入区域≠真实受损特征区域；全局扰动全 1 mask 的高 IoU
  不证明定位能力。需要局部、边界和无扰动负样本检查。
- **未见组专家**：某组完全留出后，专属专家未必学会该组；soft routing 本身
  不能保证未见组泛化。
- **可观测性**：严重雾、剪切到全黑或过强模糊可能擦除小建筑的信息，标签不变
  不意味着识别仍可解。应审查强度范围并披露信息损失限制。

## 执行决定

保留原研究问题，不预先堆叠新结构。本轮只做 Phase 1 工程基线与验证。
本轮已找到本地 LEVIR-CD，但其 32 张标签有 709 个非 0/255 像素，尚未通过严格
标签审计；明确标注工程通过/真实实验待完成，不以合成数据分数替代论文证据。
只有 Phase 1-3 结果显示强增广/普通一致性仍存在稳定缺口，
再决定是否进入 PSE/PCDC/CPC。
