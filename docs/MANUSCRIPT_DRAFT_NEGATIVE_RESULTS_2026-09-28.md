# 非几何扰动下变化检测校正动作的可行性：强基线、负结果与审计恢复的最终评估

状态：**内部论文初稿，不是已投稿论文或新颖性声明**。本稿只整理已经冻结的 LEVIR-CD 实验，不新增模型、数据读取、统计检验或分数选择。正式投稿前须由独立人员复核方法、原始产物、引用和数据许可。

## 摘要草稿

双时相变化检测在非几何成像扰动下可能同时出现伪变化与真实变化漏检。我们在原始 LEVIR-CD 的固定切分上，比较了共享 ResNet-18/FPN 变化检测器的干净训练、普通合成扰动增广（B1）与匹配曝光的普通一致性训练（B2），并进一步检验固定特征校正动作的整图选择能否超过“不校正”和“始终校正”两个可执行常数动作。扰动套件由亮度、对比度、Gamma、色偏、雾霾、阴影、噪声、模糊和 JPEG 九类、每类五级预先接受的非几何干预构成。Phase 5–6 训练分区的标签知情诊断显示校正既有收益也有伤害，并存在相对于较优常数动作的可行动空间；但 Phase 7 的四类整图选择器在一次性官方验证中均未通过预声明的主指标与伤害约束，故依规则停止该机制路线。随后 B1/B2 三种子匹配复现的验证门保留 B1：B2−B1 的平均扰动 mF1 为 −0.001018，按原始源影像对成对重采样的 95% 区间为 [−0.003249, +0.000829]。单个预先选定的 B1 seed-42 checkpoint 的 held-out test 既有一次性分数，经独立 V1R2 只读审计恢复认证，干净 F1 为 0.898428，45 条件扰动 mF1 为 0.894760；原始 V1 运行仍因最终守卫完成标记的记账错误而无效。本研究不支持所测试整图动作选择器的增量价值，也不证明所有局部或条件校正均无效。

## 1. 研究问题与声明边界

问题是：在不改变变化标签的**合成非几何扰动**下，实际执行的特征校正动作何时有益、何时有害；输入可计算的整图描述能否在干净输入安全约束下，将这种潜在收益转化为超过强常数动作的部署时收益？“潜在收益存在”与“部署时可预测、可选择”是不同命题。标签知情选择只作诊断，不是推理算法，也不被称作理论上界。

本稿定位为可复核的对照与负结果，不声称提出新型校正器、门控框架、退化识别机制或首次发现动作收益监督。已有近邻方法及其边界见[公开文献复核](PUBLIC_PRIOR_ART_2026-09-12.md)与[learning-to-defer 补充筛查](TARGETED_DEFER_AND_SELECTIVE_PREDICTION_PRIOR_ART_2026-09-29.md)；这些均非系统综述，正式投稿仍需核对出版终版与更广泛文献。

## 2. 数据、模型与冻结实验设计

- 数据为原始 LEVIR-CD，保留作者提供的 445/64/128 个 train/val/test 影像对；每对 1024×1024 被非重叠裁为 16 个 256×256 tile。RGB uint8 归一化规则、0.5 推理阈值、按作者 `label // 255` 语义处理的 `author_uint8_floor255` 标签协议均与已封存配置一致。不能把源影像对的数目当作地理独立性证明。基础协议见[研究规范](RESEARCH_SPEC.md)。
- 检测器为共享 ResNet-18 编码器、四层绝对特征差和宽度 64 的 FPN 风格解码器；无预训练权重的显式随机初始化。两个日期以同一个时相批次经过共享编码器。验证 clean F1 选 best checkpoint；test 不选 checkpoint。
- 45 个干预条件的参数、训练集视觉验收、实例种子和验证清单均在相应评分前冻结。它们模拟受控外观退化，不等同真实天气或传感器域移。各条件先汇总所有像素的 TN/FP/FN/TP，再计算 F1；扰动 mF1 是 45 个条件 F1 的等权均值，不是 tile F1 均值或 45 条件像素合并后的单个 F1。
- B1 为普通合成扰动增广。B2 与 B1 匹配初始化、扰动流、曝光量、更新预算及 BatchNorm 行为，仅增加普通输出一致性项。B0-E 控制双视图曝光。Phase 4 的 seed-42 结果见[封冻基线报告](STAGE4_FROZEN_BASELINE_RESULTS_2026-09-15.md)。R1/R1E 在 seed 43/44 重新训练匹配 B1/B2，与不可变 seed-42 一起形成三种子验证判定；R1E 是评估器兼容性失败后、在任何该批官方验证推理前另行冻结的恢复协议。
- Phase 5–6 在独立 train-only gate 源影像对上固定 detector 和共享 stage-2 adapter，诊断真实执行“不校正/校正”两动作的损失差与错误转换。Phase 7 在另行分开的 train-gate fit/calibration 源组上训练四类整图选择器 C1/G1/G2/G3，再一次性评估官方 validation。G2 `(uT,u0)` 与 G3 `(uT,uT−u0)` 目标信息可逆等价；不能将 G3 参数化称为额外信息。相应细节见[Phase 5–6](PHASE5_6_RESULTS_2026-09-22.md)与[Phase 7](PHASE7_RESULTS_2026-09-23.md)。

## 3. 已冻结的主要结果

| 问题 | 结果 | 合理解释 |
| --- | --- | --- |
| 普通增强是否比未增强 B0 更稳健？ | Seed-42 validation：B0 扰动 mF1 0.879415；B1 0.902376；B2 0.900742；曝光对照 B0-E 0.876716。 | 该受控套件中增广是强基线；B0-E 不支持“仅因双视图曝光”解释。不能把单种子差异当作普遍优势。 |
| 固定校正动作是否有可诊断的收益/伤害？ | Train-gate 的 `uT>0` 为 43,949/64,080，`uT<0` 为 19,848/64,080；标签知情实际动作选择的 mF1 相对较优常数动作增加 0.002183，成对源组区间 [0.001499, 0.003083]。 | 动作效果异质且存在诊断空间；该结果不提供可部署选择器。 |
| 整图选择器能否转化诊断空间？ | Phase 7 官方 validation 上 G0 常数动作 mF1 0.895914；八个 learned policy 的点估计均低于 G0，且无一通过预声明主指标、区间及伤害门。 | 冻结决策为 `stop_whole_tile_selector_route`；不启动 Phase 8–10 或无证据局部动作。 |
| B2 能否通过三种子门优于 B1？ | 三种子 validation：B1 平均扰动 mF1 0.900533，B2 为 0.899514；B2−B1 −0.001018，95% 成对源组区间 [−0.003249, +0.000829]；五项预声明 B2 门均失败。 | 保留 B1，而不是据较小退化 gap 或 FPR 后验改选 B2。 |
| 单个预选 B1 checkpoint 的 test 描述为何？ | V1R2 审计恢复分数：干净 F1 0.898428；扰动 mF1 0.894760；干净减扰动 0.003669；128 源影像对 bootstrap 的差值区间 [0.003140, 0.004254]。 | 仅描述 seed-42 单模型、该 held-out 切分和固定合成干预；不用于模型选择。原 V1 不能称为正常守卫完成。 |

Phase 7 的标签知情 `O` 在官方验证中高于 G0，但它依赖真实标签派生的动作效用，因此不得被写成已部署门控的成绩。Phase 4 的 B1/B2 seed-42 source-pair 区间不能单独确立 B1 稳定优于 B2；三种子预声明门才支持最终保留 B1 的开发决策。

## 4. 最终测试故障与恢复必须如实报告

原始最终 V1 在 clean 和 45 个 test 条件评分、数值汇总、原始文件再哈希及温度守卫最后检查后，写最终 `guard_completion.json` 时因本地 `_sha` 名称遮蔽发生异常。异常处理将 `status.json` 置为 `failed_incomplete_no_automatic_retry`、守卫状态置为 `failed_guard`；缺失的 marker 未被伪造。V1R 第一版只读审计又因一次性生成器求和错误停止，没有发布证书。单独冻结的 V1R2 只修正该审计器错误，重新独立核验 92,160 个 ID 派生实例、所有聚合计数和统计量、70 项原始输入字节哈希及 143 次温度观测，生成**独立恢复证书**；没有读取原始 test 图像/标签或再次推理。详见[最终测试恢复报告](FINAL_B1_HELDOUT_TEST_V1R2_RECOVERED_RESULT_2026-09-26.md)、[收口审计](../runs/final_test_b1_v1r2_protocol/completion_audit.json)与[完整性检查](../scripts/verify_research_closeout.py)。投稿措辞应为“既有一次性分数经独立只读审计恢复认证”，绝不能写“原 V1 运行正常完成”。

## 5. 限制、复现与后续证据

1. 只检验九类合成非几何干预；它们的标签不变性不保证严重细节损失后仍可识别真实变化。没有真实天气、视角/配准误差、跨区域或基础模型实验，不能外推。
2. 三个训练 seed 不足以估计一般训练随机性分布；20,000 次源影像对 bootstrap 不能替代跨 seed 区间。最终 test 的 5,000 次 bootstrap 只条件于一个 checkpoint 和 128 个源影像对，不是地理总体区间。
3. 原始 R1 训练未记录峰值 GPU 显存，不能用 test 推理峰值代填。不同阶段时长的定义不同，比较计算成本需按同一计时边界重算或明确限制。
4. Phase 7 只否定**已测试的整图描述器与选择器组合**，不否定所有可能的局部动作。没有证据支持把标签知情诊断直接升格为可部署方法。
5. 完整性复核运行 `E:\Download\anaconda3\envs\geosa-basa\python.exe -m scripts.verify_research_closeout check`；冻结产物及后续新证据准入条件见[研究收口](RESEARCH_CLOSEOUT_AND_NEXT_EVIDENCE_GATE_2026-09-27.md)。验证工具仅检查产物和决策链，不重算模型预测。当前 held-out test 已使用，不再进行 B2/其他 seed、阈值或机制对比。
