# 后续候选：互斥时间局部动作的效应预测

2026-10-27。本提案写于真实四区域探针出分之前，来自等成本强对照的逻辑审计。
不是当前冻结探针的修改，也不是已证实的新算法；当前评价→分析→探针队列保持。
旧二动作whole-tile selector及当前四区域方案各自的失败/停止门均不能被它改写。

## 可证伪的问题

原扰动作用于单个日期，但原共享adapter同时作用A/B。这个生成事实不意味着
“只改受扰日期”必然最好：真实变化、adapter的训练目标和非线性差分可能使结果相反。
值得单独检验的是，在同一局部区域实际执行A-only、B-only、both与none，是否产生
仅用旧both/none无法达到、且在可观测输入下可以预测的任务收益。

复用原frozen actor、同一个frozen共享adapter和固定观测残差，不引入新专家、
foundation model、几何变换、clean输入参考或真扰动元数据作部署条件。
同一区域四种动作互斥；不同区域仍要求传播后的影响支持互不相交。
本提案尚未实现这些动作、预测器或训练，不能把概念表当实验。

## 与已被否定的成本论据的区别

原四个兼容动作可一次全部执行，再恢复所有选择；其先预测方案没有稠密decoder次数
优势。这里同一区域的A-only/B-only/both不能同时表示在一个输出中；但强对照也不必
逐区域逐动作解码：分别执行“全部区域A-only”“全部区域B-only”“全部区域both”，
加baseline共4次decoder，便可在可组合性成立时恢复各区域/子集组合。
候选的baseline+先预测后联合执行为2次，而不是相对K或3K次。是否更快必须完整测量
encoder、adapter、统计/cache、预测、解码和拼合，不能只报次数或忽略零动作。

时间交换对称性已有STAR/ChangeMask等明确近邻，参考归一化/cache已有TIN/SIGE；
这些均只作已知组件。候选的待证问题是实际互斥动作效应预测的准确性、任务增量和
计算权衡，而非对称性、多个头、动作路由、分数优化或有限集求解本身的首次提出。
完整直接近邻核对仍未完成，当前不准入新训练。

## 任何实跑前的必要门

1. 先完成当前队列及其按原门做出的判断。不得以本提案替换、放宽或选择性删去旧结果。
2. 补齐最接近操作选择/时间质量校正方法对齐，明确还能成立的具体贡献。若只是普通
   门从2选项变4选项，不能把它包装成新原理。
3. 单独版本化CPU工程：实际原始a0/both重放、A/B交换后的动作身份对应、互斥冲突拒绝、
   多区域组合、四次解码强对照、真实调用计数和原模型/输入身份。源/协议封存及全项目
   测试通过后，才可依据实际原48小时余额讨论一个小train-only probe。
4. 在实数据前冻结动作、来源、原条件、精度、成本上限及额外动作空间的增量门。
   分别报告2动作与4动作理想上界，后者多出来的机会不是可部署改进。真受扰日期与
   真值知情动作只能是诊断。没有额外可行动余量，就停止这个动作空间。
5. 若允许学习，比较同输入/容量/数据/预算的普通局部门、实际loss价值回归、净计数与
   gross伤害预测，以及4次解码的postselection。用同一预测器比较选择规则，避免同时
   换信息、容量、目标后给单个组件归功。净计数仅两个自由度；gross头不是新信息证明。
6. 明确F1 plug-in与期望F1差别，部署基准真值计数不可知；预测约束不继承实际计数的
   精确风险保证。原fit/cal都经过开发使用，仍需多seed、强普通基线和未消费的独立证据。

这是一条备用科学问题，非自动扩大当前训练批次、自动续训或重置预算的许可。
若没有可辩护贡献或实际余额，不启动；不能因服务额度恢复就扩展原科研计算上限。
