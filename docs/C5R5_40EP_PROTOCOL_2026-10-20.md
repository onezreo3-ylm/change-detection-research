# 独立40轮C5/R5普通对照

2026-10-20。用户明确选择“总计最多48小时，两行各24小时”，在100轮方案因预算预检
未准入后，又明确批准“改为40轮独立对照”。本协议是独立批次，不修改原100轮协议、
配置、封存源码或预算失败现场；不将原pilot权重当作训练起点，不准入M5/K5/W5或新方法。

## 唯一日程变更与比较范围

两行均从原seed42随机初始张量重新开始；train.epochs和CosineAnnealingLR.T_max均为40，
其余完全继承C5R5_ORDINARY_CONTROL_PROTOCOL_2026-10-20.md。新checkpoint flavor明确为
matched_five_view_baseline_40ep_v1，不能改写成旧flavor以通过旧评价器。

每轮11025个原Sion train源各一次、2757次成功更新，最后一个batch保留一源；每行40轮
合计441000 source draws、110280成功更新、2205000 pair views。两行共享原100轮计划的
前40轮source、实例和候选像素流；C5仍实际使用五个clean，R5实际使用clean及uu/uv/vu/vv。
监督权重1/2及四个1/8，单次五view forward和双时相联合BN。原四族/等级1、3、5及
有放回u/v实例、全局扰动、退化实例保留、FP32 CUDA、batch4、模型、初始化、BCE+Dice、
AdamW、梯度裁剪、mean/std、0.5阈值、原train/val划分均不改。每轮仅干净val选首次最高F1。

主要比较是同40轮C5/R5。原B0-E为100轮、不同view和source顺序，仅作不匹配历史背景，
不能把新40轮与旧100轮差异解释为同预算方法因果效果。原C5/B0-E背景保护门仍报告，不放宽。
R5/C5的原mF1至少+0.005及clean F1/Recall/空tile FPR各保护门完整继承。
