# 原始尺度窗口上下文诊断结果

2026-10-25，Asia/Shanghai。本轮真实 pilot、四臂诊断和独立保存结果核对均已完成。预注册的窗口敏感性资源门通过：B0-E 与普通 B1 seed42 都有 7/16 张固定训练源达标，门槛为各模型至少 4/16 张。该门只支持进入下一协议讨论，不构成准确率改善、泛化、机制或新方法准入。

## 实际执行范围

使用冻结的同 16 张原 train 源、两个原 checkpoint、原 geosa-basa/PyTorch、RTX3060 Laptop、FP16 和 channels_last。共享 ResNet18、绝对差 FPN、全部参数和缓冲均保持不变，优化器更新为 0。没有读取 raw val/test/Martigny，没有几何变换、重采样或模型训练。

四臂主比较统一 batch4，分别为原 256 网格、另一组 256 读取窗口、普通 256 重叠概率均值和 512 原尺度窗口。另用原 batch32 重放原网格。A/B 始终读取相同绝对坐标，重叠处先以 FP32 平均概率，再以固定 0.5 阈值二值化。

跨臂主比较严格使用每源 `[128:896,128:896]` 的共同中心支持，即 589,824 个同坐标像素。全图支持结果单列；另一组窗口的未覆盖外部保持缺失，不评分。F1 等指标按汇总 TP/FP/FN/TN 计算，不把像素或 patch 当成独立源。

## 资源门和数值控制

预注册门为每源另一组窗口相对原网格的中心二值分歧率达到 `max(0.001,10×该源batch4/32数值分歧率)`，两模型均须至少 4/16 源通过。实际两个模型均为 7/16；逐源门和原始分歧数全部报告在 JSON，没有依据结果修改门槛。

| 模型 | 达标源数 | 窗口分歧率的16源均值 | batch4/32分歧率的16源均值 |
| --- | ---: | ---: | ---: |
| B0-E seed42 | 7/16 | 0.2772649% | 0.00007417% |
| 普通 B1 seed42 | 7/16 | 0.2562417% | 0.00006358% |

两模型的原 batch32 归档二值图及逐源混淆计数均精确重放。固定重复和双时相交换检查均精确一致，模型参数和缓冲前后相同。独立 CPU 核对直接读取新保存概率图与既有标签缓存，以整数联合编码计数和直接几何切片重算 288 张表，全部一致；概率范围、覆盖和支持外缺失正确，资源门也独立重算通过。

这些控制支持“固定模型的同一像素预测随读取窗口而改变，超过批尺寸数值参照”的有限结论。窗口同时改变卷积边界、周围上下文和六个 GroupNorm 的输入空间统计，本实验不能分离这些原因，不能将分歧归因于 GN。也不能把既有普通重叠或大窗口方案称为论文创新。

## 工程与资源结算

本轮新增独立 CPU owner、温度 guard 和 watchdog 适配；worker 在身份绑定和独立保护就绪后才导入 CUDA。PID/创建身份、原 GPU UUID、共享锁、外部墙钟、进度与心跳均绑定。2 秒级温控沿用 85°C 确认、86°C 立即停，未发生停止或重试。

实现后运行完整 `python -m unittest discover -s tests -v`：501 项通过。原 ResNet18/FPN 宽64的显式 CPU FP32 合成 smoke 通过，四臂共30个合成 pair，只作为工程检查。完整测试子进程墙钟127.2644秒，smoke子进程3.0177秒，均计入原共享账本。
