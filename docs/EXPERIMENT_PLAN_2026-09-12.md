# 最新实验方案：动作收益与损伤监督

方案日期：2026-09-12。执行边界更新：2026-09-13（中断后续接）。
来源：任务“后续实验流程详细一点”2026-09-12 21:12 的最后一条方案答复。
本文固定该方案的十步路线，不把建议、尚未执行的步骤或合成工程检查写成研究结果。

主线：通过受控的非几何扰动，学习具体校正动作的收益与损伤，减少伪变化，
同时避免校正新增真实变化漏检。公开论文和可读预印本是本轮排重范围；
不围绕未公开稿件展开。PSE 类型识别暂作诊断对照，MoE 暂不加入，
普通输出一致性必须作为强基线。收益差分、增加预测头和允许不校正均不单独作为创新点。

## 第三步：建立固定扰动基准

九类非几何扰动各五档强度，共45个类型×强度基础条件：

| 组 | 类型 |
| --- | --- |
| 外观 | 亮度、对比度、Gamma、色偏 |
| 光照/大气 | 阴影、雾霾 |
| 细节 | 噪声、模糊、JPEG |

方向、作用时相、局部/全局方式及复合顺序是清单的一部分，不能把这些差异
混入同名条件后不记录。第一版参数范围是**带明确版本号的 candidate YAML**，
并非本方案已指定或接受的最终数值；本文件不另造“最终强度”。

要求：

1. 参数范围只用训练集样例校准；保存来源影像ID、种子、参数、方向、时相、
   区域和版本。QA检查目标是否基本可辨认、是否过度裁切/遮蔽及边界伪影。
2. 训练时对称随机选择A或B；同一时相不能长期固定承担扰动。
3. 验证/测试使用彼此独立且固定的扰动清单；测试清单的设计不授予测试数据访问。
   参数版本通过train-only QA后再冻结正式评价条件。
4. 主基准局部区域生成不读真实变化标签；与变化区的重叠只用于事后分层分析。
5. no-op严格保持输入；标签、分辨率和几何对应不变。不得引入配准、平移、旋转等。
6. 注入区域只称“扰动注入区域”，不是已证实的真实特征损伤图。

产出为候选配置、固定清单、强度示例、train-only QA与工程测试报告。
未经QA的配置和示例不能被命名成正式鲁棒性结果。
每次代码改动后由主执行流程运行 `python -m unittest discover -s tests -v`
及CUDA smoke；smoke只证明工程可运行，不证明研究效果。

## 第四步：确认问题存在，并训练强基线

先在协议冻结后用既有checkpoint测**验证集**退化，再开展独立训练：

| 编号 | 内容 | 作用 |
| --- | --- | --- |
| B0 | 已有clean baseline | 原始参考 |
| B1 | clean + perturbed，均有变化监督 | 普通增广强对照 |
| B2 | B1 + 普通输出一致性 | 普通一致性强对照 |
| B0-E | clean + clean双视图 | 需要归因额外曝光收益时补做 |

B1/B2使用相同扰动、样本数、初始化和优化步数；双视图前向顺序、合批方式及
BatchNorm更新方式写明后冻结，不把“顺序两次”与“合批一次”默认视为等价。
报告实际更新数、AMP跳步和前向成本。

记录clean F1、corruption mF1、45条件分项、变化Recall、背景误报率和固定验证
样例FP/FN。每个条件先累计整个split的混淆计数，再计算指标；不得平均tile F1。
corruption mF1如何跨条件平均也须固定，不能用不同条件像素混池掩盖差异。

继续条件：B2在合理强度下仍有明确的伪变化误报或真实变化漏检。
若简单方法基本解决问题，先重新界定剩余问题，不自动增加校正结构。

## 第五步：建立共享、冻结的校正动作

这是与前述全train强基线分开的**机制试验协议**，不是复用旧权重便可开始：

- 原官方train的445对影像固定划分为356对actor、89对gate，按原始影像对分组。
- **检测器与校正器都只在actor子集训练**；gate子集生成收益监督并训练决策器。
- 原val用于选择设置，按clean val F1选择checkpoint；test保持不动。
- 所有机制对照使用同一内部划分；不改官方划分文件，相关tile/扰动副本不得跨组。
- 旧全445训练checkpoint不能冒充未见过gate子集的检测器。

校正器先用一个轻量残差adapter，放在stage 2输出接入解码器的位置，残差末层
零初始化。先不搜索多个插入层、不加多个专家。训练后冻结检测器与校正器，
包括BN状态；所有门控共享同一组模型和动作。

产出：固定模型与两个可执行动作——不校正/校正。本批不实现或训练这些组件。

## 第六步：生成真实可执行的收益监督

第一版是整张tile二选一，暂不做逐像素门控。对同一`x=(I1,I2)`与`Tx`，实际
运行clean/perturbed × 不校正/校正四种组合：

```text
uT = L0(Tx) - L1(Tx)
u0 = L0(x)  - L1(x)
a  = uT - u0
```

`L0/L1`使用同一明确任务损失；当前Dice按样本计算，不能直接拆成独立像素收益。
模型冻结并处于`eval()`，收益标签停止梯度。真值、clean对照和真实扰动信息只
用于训练期监督/诊断；推理决策器仅接收实际输入及可计算的模型特征。

`a>0`不代表动作有益；仍需检查`uT>0`和clean损伤。该差分也不自动构成
真实世界因果效应识别。

先比较始终校正与“知道标签后选择**实际动作**”的诊断参考。后者只评估动作
选择空间，不作主方法，不称F1理论上界，不通过逐像素挑选输出伪造可执行动作。

继续条件：确实同时存在受益与受损样本，并有值得学习的选择空间。

## 第七步：先排除普通收益门控和公式换写

决策器保持同输入、同容量、同初始化、同训练预算、同动作集合：

| 编号 | 监督/策略 | 作用 |
| --- | --- | --- |
| G0 | 始终校正 | 检查选择是否必要 |
| G1 | 预测扰动收益`uT` | 普通收益门控 |
| G2 | 预测`uT,u0`，可直接计算差值 | 同信息量强对照 |
| G3 | 预测`uT,a` | 检验参数化/优化效果 |

G2与G3信息等价：`a=uT-u0`，`u0=uT-a`。G3不是通过公式获得新信息。
归一化、损失尺度/权重、样本与标签生成成本都必须可比。
分别为G2/G3做有/无**同一损伤约束**的2×2消融，并补普通前景加权损失对照。

只胜过少一个预测头的G1不足以支持机制创新。若G2同样有效，采用更简单方案，
不强行保留新名称。预测clean风险不是安全保证，约束需由独立实际动作结果检验。

## 第八步：扩展到局部校正，验证实际影响范围

仅在整tile动作研究清楚后开展。候选小动作集示例是不校正、全图校正、四象限
分别校正；这是待冻结示例，不是本批已接受的最终动作集。
第一版每tile只选一个动作，避免组合区域产生未建模相互作用。

每个动作必须真实经过解码器并计算整tile任务变化，同时统计区域内/外影响。
不能把不校正输出和全校正输出按像素选优，冒充局部特征校正；卷积会使影响
超出动作区域。

比较注入区域驱动的诊断对照、普通多动作代价敏感选择、实际收益/损伤监督
选择，以及它们施加同一损伤约束的结果。所有选择器共享动作集合。
候选贡献是实际校正影响的建模，不是增加空间mask。

## 第九步：明确检验是否误伤真实变化

对不校正→实际选定动作后的预测，统一记录：

| 转移 | 含义 | 比例分母需对应 |
| --- | --- | --- |
| FP→TN | 消除误报 | 不校正时FP |
| FN→TP | 找回变化 | 不校正时FN |
| TP→FN | 新增漏检 | 不校正时TP |
| TN→FP | 新增误报 | 不校正时TN |

同时给原始计数与分母，零分母处理写入评价协议。按扰动与变化区重叠、小变化
区域/边界、校正区域外、clean输入、未见扰动分层。
新增漏检约束必须与普通类别加权和代价敏感选择比较，防止把增加前景权重
带来的效果误归因于新机制。

继续条件：在相当clean表现和变化召回下比强对照消除更多伪变化，或以更小
新增损伤获得相当收益；不能只看总体F1或平均收益。

## 第十步：机制成立后再做完整实验

依次扩展，均以独立、明确记录的协议执行：

1. 全train利用：用交叉拟合等生成收益监督，检查折内模型与最终全量模型
   的收益分布是否一致；不直接把机制试验gate图重新用于actor拟合而不改标签。
2. 联合训练：固定教师快照或统一标签刷新周期；`detach`不能阻止随模型更新
   发生的收益目标漂移。
3. 三个独立训练种子，例如42/43/44，报告均值与标准差；当前不是已完成三次训练。
4. 公开近邻：经确认后按共同协议适配关键方法，披露与作者配置差异，不能直接
   拿论文分数排名；不据此自动引入本方向禁止的基础模型。
5. 未见/复合扰动：留一类型或组需要对应重新训练，留出内容不得用于调参。
6. 最终test：方法、超参数、动作集、阈值和评价清单全部冻结后显式统一评估。

置信区间按原始影像对作成对重采样，不能把相关tile当独立样本。
计入标签生成、额外前向、校正分支、决策器全部成本；门控若先运行了校正器
才做决定，不能声称节约了该次校正计算。
