# 后续实验重规划：边际匹配的双时相扰动耦合研究

日期：2026-10-07。状态：研究提案，未实施、未训练、未新增模型推理。

## 1. 决策摘要

建议不再把 PSE/PCDC/CPC、整图动作选择或双风险梯度投影作为默认新方法主线。
新优先问题是：**当每个时相看到的扰动边际完全相同，仅改变两时相扰动的配对关系时，
变化检测是否仍发生稳定且有任务意义的失效？普通增强和普通一致性为什么没有解决？**

暂定题目：**非语义成像扰动下的双时相耦合鲁棒性：边际匹配诊断与变化证据保留**。
这是优先验证的研究问题，不是已经成立的新算法。建议先争取可复核的问题/实验贡献，
只有发现普通方法无法解释的残余机制，才投入方法创新。不能保证原创优先权、有效性或发表。

这次调整与10月4日路线不同：不研究新的优化器投影，不学习校正/回滚门，不预测扰动类型，
而是把**单图退化**和**双图退化如何配对**分开。现有证据尚未证明后者就是本项目的病因。

## 4. 核心实验：每个时相的输入不变，只交换配对

对一个真实train图像对(A,B)，生成两枚已通过可见性审阅的扰动实例u、v：

| | B_u=T_u(B) | B_v=T_v(B) |
|---|---|---|
| A_u=T_u(A) | X_uu | X_uv |
| A_v=T_v(A) | X_vu | X_vv |

比较对角两格D={X_uu,X_vv}与交叉两格O={X_uv,X_vu}。
两组都各使用A_u/A_v/B_u/B_v一次，所以**每个时相的经验边际严格相同**。
它比“单边扰动与双边扰动直接比”更能控制单图退化量；后者改变了边际和总退化预算。
不把D叫完全无失配：相同算子作用于不同原图仍可能产生不同裁切和可见性影响。
不把O叫天然更难：方向必须由实验决定。

主实验开始只用全局brightness/contrast/gamma/color_bias，避免把空间遮挡、噪声纹理相关性和
非可逆信息损失一次混在一起。这是新机制诊断子集，不替换或删减原45条件主评价。
u/v采用同一类型/等级范围的两个确定性参数抽样；抽样种子及所有像素实例在评分前封存，
不按预测挑选相反方向或困难样本。若离散实例相同，记为退化对照，不悄悄重抽。
新组合需train-only复核；旧单边可见性接受不自动意味着双边组合已接受。

以后若扩展shadow/haze/noise/blur/JPEG，必须分别登记参数相关性、空间场相关性、作用区域、
随机场seed和双边可观测性；共享噪声实现可能造成不自然的抵消，应作为独立人工诊断，
不能声称代表真实传感器噪声。全程不改变几何和标签。

### 测什么，不测什么

所有四格输出分别保存任务计数及clean到该格的TP→FN、FN→TP、TN→FP、FP→TN和分母。
报告D、O各自pooled F1/Recall/FPR及绝对差，不平均tile F1。
分层包含空/非空、既有标注面积层和扰动类别；不用标签指导扰动生成。

可在logit上计算描述量：

```
m = (z_uu + z_uv + z_vu + z_vv) / 4
a = (z_uu + z_uv - z_vu - z_vv) / 4
b = (z_uu - z_uv + z_vu - z_vv) / 4
i = (z_uu - z_uv - z_vu + z_vv) / 4
```

a/b是此四点设计的单时相主效应，i是混合响应，不是真实变化成分或因果损伤图。
若z=c+f(u)+g(v)，i恒为零，但模型仍可能强烈依赖扰动。
即使D/O平均logit相等，非线性任务损失及阈值F1仍可能不同。
因此不能用i变小代替准确率改善；必须共同报告主效应、四格风险和像素交换。
二时相互换对当前共享编码器+绝对差分模型在eval时本就应对称，只作实现自检，不算新贡献。

## 5. 分阶段执行，而不是一次启动十几次训练

### P0：文献/工程准入与便宜机制诊断

1. 完成最接近算法的全文/代码对照：输入、扰动联合分布、目标、推理信息、预算各列一栏。
2. 仅用Sion train，按固定哈希选16个正tile和48个空tile；正tile覆盖既有面积层，
   不足层的补齐规则提前写入配置。这是富集诊断样本，不代表自然分布发生率。
3. 复用B0/B1/B0-E三个冻结checkpoint，eval模式；四类×等级1/3/5×四格，加clean。
   完整上限为9408个tile-pair预测；先测吞吐，GPU预算上限6小时，到限标记incomplete。
4. 不做梯度、不改优化器、不推进原checkpoint，不读val/test来筛选u/v。
5. 明确数值复现、边际图像哈希相等、重复/退化四格和时相交换自检。

进入普通控制的建议实用门：B0-E与B1都至少在两个预定扰动族出现D/O pooled F1绝对差
≥0.005，且有非零、可复核的有害像素交换。两模型各自报告，不把该门当显著性结论。
这个门是在旧结果后提出的新筛查门，必须在本次预测前冻结。
若仅有logit变化却没有任务效应，或只在不可辨认强度出现，不推进新方法。
该门只筛选耦合问题，不证明i是病因，也不授权直接上混合差分正则。

### P1：两个普通基线，排除已有显著混淆

优先实施已有B0-E-S采样提案，并训练相同source流的A-S增强对照：

| ID | 内容 | 用途 |
|---|---|---|
| C-S | 分层采样，clean+clean | 检查普通正类曝光能解决多少clean漏检 |
| A-S | 同一分层source流，clean+原扰动 | 检查改善普通基线后是否仍有增广损害 |

保持原模型、FP32、初始化、loss、AdamW、100轮、固定0.5阈值、首次最高clean-val F1选模。
采样重复数采用10月4日已有精确提案，不重新根据Sierre挑样。
原45条件完整评价；新耦合评价另建版本和train-only QA，绝不覆写旧清单。
两条完成后对其train预测重做P0。若普通控制已解决目标失效，结束方法路线。
若clean问题依旧严重且耦合效应不稳定，优先完成数据/采样/BN机制研究，不再自动加结构。

### P2：只有残余耦合问题成立，才做匹配方法筛查

为了让额外信息和计算不成为伪创新，所有本阶段行使用完全相同的clean+四格共五个pair views，
同source/扰动流、相同训练更新数及一次联合BN更新。新五view协议单列：不与历史双view
行声称曝光/BN完全相同。不得因显存不足静默改batch、精度或换设备；先测工程pilot并审阅。

| ID | 设置 | 定位 |
|---|---|---|
| R5 | clean监督权重1/2，四格监督各1/8 | 必须有的全因子普通增强基线 |
| K5 | R5 +四格普通概率一致性 | 排除多视图一致性解释；使用现有B2实现作适配起点 |
| M5 | R5 +针对i的有限差分正则 | 仅为任务化机制候选，不叫新二阶优化算法 |
| W5 | 同五view，以耦合组做现有最坏组风险控制 | 若M5有收益，必须补齐，排除普通DRO解释 |

M5的最简待审目标是lambda·mean(i²)，前景/背景分别报告响应但第一版不引入新的
类别权重、校正头或学习门，避免与普通Recall权重混淆。它只允许用于“残余失效确与混合
响应有关”的情况。lambda及K5/W5权重的候选集合、相同调参次数与选择规则须先行审阅冻结；
本文件不把未定超参数伪装成可直接执行协议。

关键否定对照：普通全方差一致性，及只约束a/b的同量纲控制。若M5效果由主效应抑制、
普通正则强度、较多曝光或一般最坏组优化解释，撤回“混合响应特有贡献”。
不能只展示i下降，也不能把混合差分的已知数学重新命名为独立发明。
还需排查logit整体缩小、输出趋常数及更多依赖单时相先验的退化。阈值0.5仍是唯一主评分点；
可预先冻结附属PR/阈值敏感性报告但不得据其改部署阈值。train-only时相信息消融必须单列，
若打乱partner，原change标签不再是有效真值，只能做输入依赖诊断，不能计算所谓有标签准确率。
若该目标不值得实施，保留R5/K5/W5形成可靠普通方法边界，不强行保留M5。

### P3：确认、未见耦合与外部证据

只为通过P2的主候选、最强普通控制及必要增强基线增加seed43/44。
同seed严格配对；seed42是开发，另两个是随机性确认，不是两个新城市。
训练前设计未见的扰动配对/联合分布，单时相边际保持匹配，清单不参与调参；
这只能叫未见耦合确认，不能叫未见扰动族或独立场景泛化。

原LEVIR只复用train/val作明确标注的已开发域补充，旧test不重开。
Valais Martigny test在方法、超参数、报告终点全部冻结前持续封闭；最终访问需另列执行批次。
独立外部建筑变化数据需先审查来源、许可、空间划分/缓冲、标签和train QA，再讨论确认实验；
不以随机相邻tile划分冒充外部独立证据，不自动下载或增加新数据集。

## 6. 评价与去留规则

原45条件mF1是既有兼容终点，保持条件等权且每条件先池化像素。
新耦合套件同时报告D/O、两者较差F1、均值F1、Recall、空tile FPR和clean表现。
将“较差组变好”与“好组被拉低造成差距缩小”严格分开。

建议P2新开发实用门（执行前绑定配置/代码哈希）：

- 相对同五view最强普通控制，新耦合较差组F1至少+0.01；原45条件mF1至少+0.005。
- clean F1下降不超过0.005，clean及扰动Recall下降不超过0.01。
- clean与扰动空tile FPR增量分别不超过0.0002。
- 净FN、原始TP→FN和FN→TP分别报告；clean起点降低不能用于缩小鲁棒性gap。
- 三seed确认时新耦合较差组F1增益每seed均为正，且每seed通过保护门；全部失败也公开。

这是预算筛查标准，不是统计显著性、安全保证或原创性证明；不能回溯改写旧B1/门控结论。
M5胜过R5但未胜过K5/W5，只能说明特定正则有效，不能宣称新的耦合机制优越。
如未完成最接近方法适配，就明确只完成内部控制，不能说已超越文献。
Valais无可信空间source IDs，不做tile bootstrap，不把四格、45条件当独立样本。
后续有可信原始source/空间单元时才做组级成对区间；三个seed也不替代地理重复。

## 7. 时间与产出

当前只建议批准P0的低成本独立诊断，最多6 GPU小时；本次写方案不构成诊断执行。

确有可复现证据且文献排重通过；不是事先保证有一篇论文。
