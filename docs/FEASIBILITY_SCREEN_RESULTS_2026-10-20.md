# 有限可行性筛查结果（2026-10-20）

用户授权“好，开始执行”后的独立批次已完成。结论：**五view普通监督在现有设备上可做一次真实更新；自然分布BN重校准未恢复C-S/A-S，混合响应新方法仍未准入。**
这批执行了保存结果归因、固定train子集的BN统计干预和一个R5工程更新，没有新增研究效果训练或验证集推理。

## 采样与漏检定位

原数据11025个train源中1046个含前景，正源占9.4875%；C-S/A-S每轮抽2757次正源，比例25.0068%。
正源曝光为原均匀流的2.6358倍，空源曝光为0.8285倍；均匀batch全空的理论概率为67.1134%，分层batch为0。
100轮的正像素抽取总量：B0-E为111842300，C-S/A-S各294816657。该变化同时改变重复、batch组成、BN上下文和优化，尚未隔离病因。

C-S/A-S相对B0-E的空tile clean FP各增加10391/42565。简单增加正源曝光没有解决总体漏检及误报取舍；后续不能继续把“正样本不足”当作已证实主因。

## 固定train-only BN干预

沿用原P0的16正/48空、共64个train probe源；它们均为训练及开发时使用过的富集样本，没有独立性或自然分布保证。
两校准臂均排除probe，按固定hash从train选256源：uniform为29正/227空，stratified为64正/192空。源名不重叠不代表空间独立。
每模型各臂从原checkpoint恢复；两校准臂只reset/累计BN统计64次，每次4 source、clean+clean、一次双时相联合forward。
没有梯度或优化器更新，所有学习参数及非BN缓冲逐位不变，结束后完整恢复原状态。未导出校准checkpoint，也未以probe挑选部署方案。

分层校准对C-S F1仅+0.3931个百分点，对A-S为−0.1875个百分点；B0-E的F1改善也伴随Recall下降。没有一致的恢复证据。
因此不采用“统一重校准BN即可修复”的方案。这不证明BN与原退化无关：样本量、reset及深层batch统计仍有限，当前只检验了这两个预先固定的统计干预。
原始臂64源逐源clean计数精确复现原P0/残余记录；共576主probe预测、18次重复/交换自检、384校准forward/3072校准pair views。
全部576条记录的面积/像素池化、相对原臂错误交换守恒审计通过。诊断耗时211.328秒，最高观测温度62°C。

## 残余交互的解释限制

复用保存记录，排除原来u/v完全相同的退化四格，在固定正源上同时汇总m/a/b/i能量，不新增预测或选择条件。

| 族 | C-S：i/合并主效应 RMS比 | A-S：i/合并主效应 RMS比 |
| --- | ---: | ---: |
| brightness | 0.4746 | 0.4383 |
| contrast | 0.4077 | 0.3131 |
| gamma | 0.4584 | 0.3106 |
| color_bias | 0.5032 | 0.6441 |

比值为sqrt(sum(i²)/(sum(a²)+sum(b²)))，按前景像素和条件池化。色偏比值反而上升；这些描述不能证明交互为主要病因，更不能用i降低替代较差组F1提高。
没有执行M5、a/b干预、K5/W5训练、多个seed或新地域确认。原D/O方向反转、好组下降和单seed局限继续有效。

## R5工程pilot

通过一次真实FP32 CUDA更新：4 source×5 views=20 pair views，clean权重1/2、uu/uv/vu/vv各1/8，原模型/seed42初始张量SHA256精确一致。
使用原P0按既有顺序首个正源与首三个空源及封存gamma L3四格，没有挑选大分差、改变强度或重抽u/v。
AdamW成功更新1次；loss=1.746726990，裁剪前梯度范数=7.473894596，每层BN计数恰增加1。所有更新参数有限。
峰值PyTorch allocated=2.3567 GiB，reserved=2.6504 GiB；这是本进程分配器统计，不含其他应用全部显存。
单次更新观测1.781秒，最高温度51°C；单步结果不代表整轮稳定吞吐或训练效果，不据此估计总训练时长。
没有导出或评分pilot权重；未作研究F1，也未以此挑选超参数。

首次启动的显存查询遗漏明确device index，PyTorch 2.0.1拒绝调用。异常发生于forward之前，0 pair views、0优化步。
旧脚本、旧封存哈希及失败report保持原样；新独立入口仅修正该查询，并另作封存和检查。
两次启动的累计pilot guard时间为3.797秒（原启动0.969秒），总实际更新仍为1，不隐藏启动开销。

## 验证、预算与去留

最终377项项目全量unittest通过；此前374项测试及三模型真实CUDA smoke也通过。测试是工程证据。
原1137个输入与启动修正的附加输入均封存/重核通过，原checkpoint、配置和核心实现未改。最终保存审计通过。
本批真实数据前向记录为3761 pair views：smoke75、BN诊断3666、R5工程20；此外有测试、加载、哈希和启动开销。
上述均作为本批额外物理计算，不并入旧有效训练预算。旧C-S95轮、A-S97轮至少1100步及较早暂停后未知精确废弃步数继续披露。
Martigny与旧LEVIR test关闭；未新增val图片/标签读取或推理，仅分析原保存val计数。90分钟托管保持PAUSED，所有本批研究进程已退出。

**本批决定：保留R5作为普通对照候选，M5继续暂缓；不自动启动正式P2或新100轮训练。**
下一项可审阅的普通效果比较应以现有较强的均匀采样B0-E为参照，并新建同五view的C5（clean重复五次）/R5对照，
使两者source流、有效更新、五view曝光及联合BN完全匹配；不能将R5与历史双view B0-E称为计算/BN等预算比较。
这一比较仍需要单独固定训练终点、有限预算和原clean/Recall/空tile误报保护。若效果不优于强普通控制，就结束当前方法主张。
本批既未证明R5有效，也未补齐混合响应的机制、主效应/尺度否定控制和最近文献的完整可复现比较门；不能进入M5正式训练。
