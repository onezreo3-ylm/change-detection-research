# 参考统计重放的近邻结论

2026-10-27。本轮改变下一步：**不将参考统计公式本身作为新归一化算法贡献**。
已完成CPU原型保持有效的数值检查，不能由此证明新颖性或任务收益。候选方法需转向
具体的空间动作组合与联合代价预测，并接受普通输出掩膜及同信息量策略的否定对照。

## 直接同构部分

[TIN v2，§Thumbnail Instance Normalization式2](https://arxiv.org/html/2103.11784v2)已经定义
`TIN(x,t)=gamma*(x-mu(t))/sigma(t)+beta`，使用参考thumbnail的统计处理patch。
本地`y1=y0+gamma*(z1-z0)/sqrt(var(z0)+eps)`在精确算术中就是使用z0参考统计的同类仿射
归一化；把通道统计改成分组统计、参考改成无动作分支，不足以单独主张新原理。
差分实现保留有限精度零动作恒等，是工程性质，也不改变这一近邻关系。
实际阅读v2引言、方法式1–4和实验/限制相关段落；v3书目信息仅从arXiv入口核对，
没有把v2正文冒充v3全文阅读，也未取作者权重或复现跨任务分数。

## GN分块文献的约束

[Buglakova等，arXiv v1](https://arxiv.org/html/2503.19545v1)实际核对§3.2、§3.3、
§5–6及其方法/结果上下文：输入/特征统计范围、running statistics、train/eval差异和
tile mismatch均有明确分析，BatchRenorm是其所比较的方案。这里不替换原生产GN，
也不宣称首次发现空间统计造成非局部依赖。训练期直接固定统计的稳定性仍须另测；
已有原型仅冻结decoder并让梯度通过动作，不覆盖从头训练encoder/decoder的数值稳定性。

## 下一可证伪命题

在同一冻结参考、固定action residual和互不相交的卷积影响支持下，逐层参考统计使动作
没有额外全局统计耦合，因此联合执行的输出应与单动作结果在各自支持内拼合一致；
FP/FN等计数增量可以精确相加。普通“联合特征动作后再掩膜输出”仍可能在区域内因GN
统计相互影响，不能仅由区域外保持推出可组合性。必须实际同输入/同权重对照验证。

若该性质成立，可准备“预测局部实际动作代价、按联合约束选择不相交动作”的方法候选；
它的贡献必须来自受控的组合决策与真实任务增量，不能来自已知归一化式、多个预测头或
通用背包/成本敏感优化。若普通分支逐个解码再拼合达到同等收益，也必须报告额外解码开销
并作为对照，不能隐藏其效果。该候选仍未通过新颖性或真实效果门，不自动准入新GPU任务。
