# 当前创新性判断：公开近邻与实际证据

日期：2026-10-04。回应用户“当前创新性是否能保证”。本轮是文献与现有结果复核，
没有改变模型、训练协议、筛选门或已停止路线，也没有启动实验。

## 当前判断

**不能保证，且当前证据还不足以确认独立方法创新已经成立。**
已有的具体贡献是受控扰动评测、匹配对照及限定范围的负结果。它们有实验研究价值，
但不自动构成新的校正方法；是否形成独立实验贡献还要比较公开评测方案、补足重复
证据并限定结论。方法是否与已有研究不同、是否具有可重复的增量价值，需要分别核查。

## 已完成实验对创新主张的约束

1. [LEVIR Phase 7](PHASE7_RESULTS_2026-09-23.md) 中已测试的 C1/G1/G2/G3
   整图选择器均未通过预声明门。标签知情动作诊断空间没有在该组合中转化为
   超过较强常数动作的部署时收益。该路线的停止决定继续有效。
2. G2 的目标 `(uT,u0)` 与 G3 的目标 `(uT,uT-u0)` 可逆等价；更换目标坐标
   不增加监督信息。当前也没有支持 G3 独立优势的结果。
3. [本次 Valais 对照](VALAIS_MATCHED_RESULTS_AND_CLEAN_BASELINE_NEXT_2026-10-04.md)
   的 B1 相对 B0-E，clean F1 下降 2.78 个百分点、corruption mF1 下降 0.86
   个百分点。它否定本批普通增广的预期整体收益，不证明某个新校正机制会有效，
   也不证明所有增广/校正均无效。
4. LEVIR 中普通增广已有正结果，Valais 当前设置中的结论不同；不同数据/数值/
   训练设置之间的观察差异不能直接归因为标签稀疏、尺度或某个单一因素。
5. 当前 Valais 只有一个训练 seed、一个验证城市，且缺少可信空间 source IDs；
   不能将 1,715 个 tile 当作独立样本证明一般结论。

## 如何使后续投入服务于贡献

### 若目标是方法创新

在新增长机制实验前，应先写清一个可以证伪的区别：**相同可执行动作、推理信息、
容量与训练预算下，所提出的监督或决策是否在同一 clean/Recall 损害约束内，带来
超过普通直接收益预测、代价敏感选择和强常数动作的增量价值。**

需要比较的是具体监督/决策及其信息来源，不能依靠换名、增加分支或计算预算。
配对监督也必须胜过具有相同目标信息的控制，才能讨论参数化或学习效果的贡献。
旧选择器的失败门不能由未经检验的新名称或局部动作绕过。

下一项 B0-E-S 可以帮助排查 clean 基线与采样因素，其作用是减少后续归因混淆。
它尚未实施，也不能承担保证创新性的任务。待普通基线和残余问题核验后，才能
单列新的具体机制假说及执行协议。

### 若目标是实验研究贡献

可以围绕“哪些合成非几何条件造成漏检、普通增广在什么设置下有收益/代价、
标签知情动作空间为何未转化为可部署收益”组织可复核研究。仍需比较公开评测
和强基线、补足独立 seed/模型证据，并区分真实成像问题与合成干预范围。
负结果的严谨性能够支撑限定结论，不能替代优先权检索或外部验证。
