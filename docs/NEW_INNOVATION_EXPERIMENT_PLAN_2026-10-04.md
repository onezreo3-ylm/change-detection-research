# 新创新实验方案：配对训练更新的变化证据保护

日期：2026-10-04。状态：**研究提案，尚未实施或启动新训练**。
对应用户请求：“尽可能利用现有成果，为我制定一下新的创新实验方案”。

## 1. 推荐课题与可以证伪的主张

**建议题目：非语义成像扰动下的变化证据保护——稀疏变化检测中的配对更新约束。**

核心问题是：在同一训练样本、初始化、采样流和增广流下，普通增广的附加更新，
是否会在总体 clean 损失没有变差时，损害真实变化的学习；将前景和背景分别保护，
能否在固定误报预算内得到超过普通采样、损失调整和通用梯度方法的增量收益？

这是新的训练机制假说。现有结果没有证明其成因或有效性，文献检索也不能保证原创。
方法贡献的成立条件是明确的匹配对照和可重复增量；只有更高 Recall、增加一个约束，
或者换一个名字，都不足以成立。

建议依次检验：

- **H1：曝光解释。** 提高正类 tile 的训练曝光，可能改善弱 clean 检出；普通采样对照
  能解决多少问题需要先测量。
- **H2：被总体损失掩盖的损害。** 对同一状态的训练更新进行配对干预时，存在“总体
  clean 风险未恶化，但前景风险恶化”的情况；这在简单采样控制后仍然存在。
- **H3：分开保护的增量。** 约束实际参数更新相对 clean 监督参照的前景/背景风险，
  比只保护总体风险、只调 loss、或使用相同标签信息的通用梯度方法更有效。

主线保持现有二值双时相变化检测、共享 ResNet-18 和差分解码器。当前提案不需要
推理时的 clean 参考图、标签、扰动类型或新增预测分支。

## 5. 候选机制：以 clean 监督更新为参照，分别约束两种风险

令 `X=(I1,I2)`，`XT` 为现有非几何扰动实例，`y` 仅来自 train。
同一联合前向得到 clean/perturbed logits `zc, zt`，原监督损失为：

\[
L_c=L_{BCE+Dice}(z_c,y),\quad L_t=L_{BCE+Dice}(z_t,y),\quad
g_{nom}=\nabla_\theta (L_c+L_t)/2.
\]

在完全相同的旧 AdamW 状态下，分别计算两个**虚拟参数增量**：

\[
d_{nom}=AdamWStep(\theta,s,clip(g_{nom}))-\theta,\qquad
d_c=AdamWStep(\theta,s,clip(\nabla L_c))-\theta.
\]

`clip` 均为原梯度范数 1.0；增量包含 bias correction、momentum、二阶矩及 weight decay。
虚拟更新没有各自提交状态。`d_c` 是**同一联合 BN 条件下删除 perturbed loss 的参照**，
不等于两个纯 clean view 的 B0-E-S 实际更新。这一区别需在报告中保留。

定义可微训练风险，不把它们冒充阈值 0.5 下的 Recall/FPR：

\[
R_+=\frac{\sum_p y_p\,softplus(-z_{c,p})}{\sum_p y_p},\qquad
R_-=\frac{\sum_p(1-y_p)\,softplus(z_{c,p})}{\sum_p(1-y_p)}.
\]

对所有 trainable 参数计算 `h+=grad R+`、`h-=grad R-`，求最接近普通增广更新的增量：

\[
d^*=\arg\min_d\tfrac12\lVert d-d_{nom}\rVert_2^2,
\quad h_+^\top(d-d_c)\le0,\quad h_-^\top(d-d_c)\le0.
\]

两个半空间的小型 QP 可由梯度内积求解。`d_c` 始终为可行点。主候选不增加可调
loss 权重；零松弛、两个约束、全 trainable 参数预先固定。

实现选择需要明确冻结：

1. 应用实际参数增量 `d*`；优化器只提交 `g_nom` 对应的一次 moments/step 更新。
   这是有意改变的优化器执行协议，必须保存并验证恢复；不能声称仍是原 AdamW 数学。
2. 同一批 source 仍两个 view、一次联合前向及一次 BN buffer 更新。多次求导不能
   重复前向并累计 BN；诊断重放必须保存/恢复所有 buffers/RNG。
3. 约束使用稳定归一化法向量；缺少某类或法向量为零时，记录并跳过该类约束。
   分层完整 batch 有一个正 tile；末尾单例不伪造负标签。
4. 保存虚拟/实际增量、归一化约束残差、干预比例、保留的增广增量比例、梯度范数、
   update/曝光/BN 计数、完整优化器与 RNG 状态。非有限值或求解不满足数值门时停止。
5. 推理仍只执行原 detector 一次；新增开销在训练中的多次求导和虚拟更新。

这些约束只有同批、当前点的一阶意义。有限步长、共享 BN、代理风险、未来状态和
未知样本都可能违背预期；不得宣称“保证不伤害 Recall”。后续实际指标门决定是否保留。

## 6. 按证据推进的实验顺序

### A. 小规模 train-only 机制诊断

先复用 B0-E/B1 的 best/优化器状态做诊断，初步检查假说是否值得投入。旧验证混淆
计数不能恢复像素交换，因此本阶段必须新增明确标注为 train-only 的预测/干预记录。

- 诊断集合：64 正 tile +192 空 tile，均来自 Sion train。正类按既有 5 个标注面积
  层分配 `[13,13,13,13,12]`，按 `SHA256("valais-evidence-diag-v1|"+name)` 排序取样；
  不足层全取，余额从剩余正 tile 按同一哈希补齐。空类按哈希取 192 张。
- 组成 64 个固定 1 正/3 空 batch；清单先于推理封存。该集合富集正类，不能估计
  自然 train 或 val 的总体发生率，也不能被称为空间独立样本。
- 两个原模型在 clean 和全部 45 条件上计算四种联合转移：`TP→FN`、`FN→TP`、
  `TN→FP`、`FP→TN`；按真实前景/背景像素、面积层、族、级别、时相、global/local
  保存分母与计数。必要时存 packed binary maps，避免批量 float logits/聊天大图。
- 选上述清单中覆盖 5 层的前 8 个 batch（各层先一个，其余按哈希补足）进行单步
  干预：9 族×级别 1/3/5，两个原 checkpoint，诊断学习率固定 1e-4。
  使用原 optimizer moments/step/betas/decay；诊断 LR 是明确单列的局部干预设置，
  不是重建原训练轨迹或拟合新模型。
- 对比 `d_c`、`d_nom`、总体 clean 风险单约束、双约束，以及原始梯度冲突；在
  checkpoint 副本中重放后测实际风险/预测转移。另用冻结 BN 统计重复同样比较，
  区分参数更新与 mixed BN 的影响。固定另 8 个未参与梯度计算的 train batch 作探针；
  这些仍是已用于原训练的样本，不是独立验证集。
- 诊断最多 432 个 checkpoint/batch/condition 干预上下文；总预算上限 8 GPU 小时，
  到达上限标记 incomplete，不用不完整结果通过机制门。先做 guard/CUDA smoke。

**建议诊断门（新提案门，不修改旧结果）：**两个 checkpoint 各至少 10% 的有效
上下文出现总体代理改善/持平而前景代理恶化；对这些上下文，双约束实际前景附加
损害均值下降至少 30%，背景附加风险均值不高于 clean 参照 +1e-6。独立梯度探针上
前景效果方向一致，背景风险不高于普通增广 +1e-6。平均保留增广增量范数比例至少
25%，避免主要退回参照。比例按上下文均值计算并报告完整分布，不作显著性推断。

若观察不到掩盖现象，H2 暂不支持，停止该机制路线。若冻结 BN 后掩盖上下文减少
80% 以上，则优先起草普通归一化控制，不把现象解释成已成立的前景冲突机制。
局部干预即使通过，也只证明训练点附近的可操作性。

### C. 先比较最直接控制，再补齐普通近邻

以下各行均沿用 A-S 的采样、view、扰动、初始化、更新数与 BN；有意变化项单列。

| 顺序/ID | 唯一主要变化 | 归因作用 |
| --- | --- | --- |
| 第一批 M | 第5节双风险实际增量投影 | 主候选 |
| 第一批 Q-total | 同一虚拟 AdamW 更新，只有 `grad Lc` 总体风险约束 | 排除一般 clean 保护解释 |
| 第一批 P-FB | PCGrad，任务为 clean 前景 BCE 部分、clean 背景 BCE 部分、clean Dice、perturbed 原监督损失 | 标签信息相同的通用梯度控制 |
| 通过后 L | BCE+Tversky 替换 BCE+Dice | 排除普通 Recall 优先 loss |
| 通过后 K | 原 BCE+Dice +对称概率 MSE，weight=1.0 | 普通 B2 控制 |
| 通过后 P | PCGrad，两任务为 clean/perturbed 原监督损失 | 排除普通两 view 冲突处理解释 |

P-FB 中两个 BCE 部分均按总像素分母归一，四项各以0.5权重进入 PCGrad，投影前
加总严格等于 A-S 梯度。固定局部 RNG 决定投影顺序；PCGrad 后原 clip/AdamW。
P 则为两个各0.5权重的原 view loss。梯度信息量、求导次数和实际 compute 分别记录。

L 固定 `Tversky=(TPsoft+0.5)/(TPsoft+0.3 FPsoft+0.7 FNsoft+0.5)`，按样本平均
`1-Tversky`，BCE权重1；0.3/0.7偏向FN保护。此参数为本提案预先选择，不进行
Sierre 网格搜索；α=β=0.5时必须回归到现有 Dice，以检查实现。

第一批使用临时普通参照：C-S/A-S/P-FB 中通过保护门且 mF1 最高的行。M 须相对它
达到 mF1 +0.005、corruption Recall +0.01，相对Q-total达到mF1 +0.003，并满足
同样保护门；否则停止其方法主张。通过才补齐 L/K/P，再按第7节完整 B* 重做门。
不能在缺少这三行时宣称已胜过普通 loss/一致性/通用冲突控制。
所有条件不利结果均保留。

### D. 机制归因、确认及独立证据

主候选通过 C 才补：M 仅前景约束、M 仅背景约束；以及 **P-FB+MAdam** 近邻控制。
MAdam 需先核查公开算法、FP32/clip/AdamW兼容性并单列实现协议，不从摘要随意仿造。
若相同信息的近邻控制已解释收益，降低为已有方法的应用/实验贡献。

冻结算法后，对 C-S、A-S、M、最强合格普通控制增加 seed43/44；重合行不重复训练。
三个 seed 同 seed 配对报告全部差值、均值和范围；要求 mF1 差在三个 seed 都为正，
均值至少 +0.005，且每 seed 通过保护门。seed42是开发筛查，43/44是新训练随机性
确认；同一个已观察 Sierre 城市不能因此变成独立外部确认数据。

外部证据应只在方法冻结后安排。可优先审查 [WHU 官方 building change 子集](https://gpcv.whu.edu.cn/data/building_dataset.html)
作为后续候选，官网确认有该子集下载；本轮未取得/检查其文件，也不把同网页的建筑
提取 train/val/test 数量套到 change 子集。需要先核验使用条件、原图/标签、空间来源、
重复/相邻区域和切分，并另列协议及 train-only 强度审阅。若只有单大图，按有缓冲的
空间块定义开发/留出单位，不能随机打散相邻 tile 后声称独立。

## 7. 新实验的评分门与停止条件

这些是观察旧结果后提出的**新开发筛查门**，须在新运行前绑定配置/代码哈希；
不回溯放宽旧 B1 门。mF1仍为45条件的 pooled pixel F1等权均值。

合格控制先相对同 seed 的 C-S 满足：

- clean F1下降不超过0.005；clean Recall下降不超过0.01。
- pooled corruption Recall下降不超过0.01。
- clean及pooled corruption空标签tile FPR增幅分别不超过0.0002。

在合格普通控制 C-S/A-S/L/K/P/P-FB 中，按完整45条件mF1选择最强者 B*；
若有并列，按固定ID顺序，不根据局部族/级别排名挑选。

**主候选 M 的门：**

1. 相对 B*，mF1至少+0.005，pooled corruption Recall至少+0.01。
2. 相对 C-S与B*分别满足上面的clean/FPR保护门；不能通过降低clean起点缩小gap。
3. 相对Q-total，mF1至少+0.003并通过同样保护门，才支持分开约束的增量。
4. 最接近控制P-FB+MAdam也须完成并通过相同增量/保护标准后，才能进入方法确认。
5. 报告45条件、9族、5级、global/local、空/非空、面积层的绝对计数及分母。
   新像素交换记录按共同源计算；较少净FN不等于较少有害像素交换。

以上阈值是实用性要求，不是统计显著性或理论安全保证。Valais没有可信空间source IDs，
不做tile bootstrap，不把45次出现当45个独立样本。高面积层为预定诊断终点，不替代
总体mF1，也不设置事后最有利的“主子组”。原train/val数据不重切。

**停止方式：**

- 普通控制解释问题：结束新机制，保留匹配曝光/增广实验结果。
- H2或单步可操作性失败：停止投影路线，转为BN/曝光的受控问题归因。
- M被普通loss、PCGrad或MAdam解释：撤回独立方法创新主张，不继续加模块补分。
- seed或外部确认不稳定：限定结论，保留完整失败运行，完成实验研究稿。
- 数值/数据/温度/封存异常：保存明确状态与可恢复checkpoint，停止剩余队列，不自动重试。

## 8. 投入与产出

已完成B1历史中100轮训练加clean验证阶段共 **18.1288小时**，平均652.64秒/轮。
这不含checkpoint I/O、45条件评分、暂停或本机制的额外反向开销，不是运行时间保证。

| 关口 | 新增投入上限/单位 | 通过后才追加 |
| --- | --- | --- |
| A | ≤8 GPU小时，有限诊断；无参数持久训练 | 2次完整普通控制 |
| B | C-S/A-S各100轮；原速率约36.3小时阶段时间 | M/Q-total/P-FB |
| C第一批 | 3次完整运行，额外求导另测；先做短工程pilot | L/K/P共3次 |
| C通过后的普通控制 | 3次完整运行 | 两项单约束消融及MAdam共3次 |
| D确认 | 3至4行×2新增seed，6至8次完整运行 | 独立外部数据验证 |

完整成功路线最多17至19次新的Valais100轮运行；这不是一次性启动清单。
前8次包括B与C的完整筛查；若早期门失败，余下运行不执行。主候选预计需要多个
反向调用，训练时间/显存不可直接套用18.13小时。每行先作10轮以内工程pilot，
仅检查实现、guard、恢复与测量开销；正式结果仍按完整100轮协议，从同一初始化开始。
若额外方法训练阶段时间超过A-S的3倍，先记录成本与求导范围，停止该执行版本，
不静默缩小参数/更换精度。10轮分数不用于宣称方法有效或挑选超参数。

可以形成的研究成果：配对损害诊断、普通曝光/损失/梯度控制的机制边界，以及在
确认成功时的轻量推理训练方法。原负结果、baseline与45条件协议全部保留为证据。
不能承诺某个期刊、录用或创新成立。

## 9. 数据边界和首个执行批次

test不重新进入开发，本方案只复用其历史成果/实现。
