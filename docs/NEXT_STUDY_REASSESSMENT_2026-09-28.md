## 创新性重新判断

1. **可立即整理的成果：严格对照与负结果。** 主要贡献是可复核地表明，在该固定合成扰动与 LEVIR-CD 设定下，普通增强很强，而已测试的普通一致性及整 tile 动作选择没有通过预声明增量门。这可作为负结果/复现研究写作；不能命名为新的校正算法。
2. **下一候选问题：空间局部、真实可执行动作的影响。** Phase 7 的 1,024 维描述器对空间做了均值/标准差汇总，未给选择器像素或动作输出；收益符号诊断存在但可部署 AUROC 约 0.47–0.57。局部影响是否更可预测仍是未检验假设。先用新的独立数据的训练部分验证局部动作相对“不操作/始终操作”的可行动空间、区域外误伤和输入可预测性；若没有预设余量就停止，不直接训练 PSE/PCDC/MoE。
3. **另一候选成果：真实来源的变化检测鲁棒性评测。** 现有 45 条件是合成非几何扰动，不能替代自然成像差异。只有得到来源、许可、空间单位、标签质量明确且与 LEVIR 独立的影像对，才值得构建新开发/留出评测。单独列出真实域差异和合成干预，不能假定标签在严重遮蔽后仍可观测。已有遥感鲁棒性基准及变化检测近邻使“多扰动 benchmark”本身不足以证明新颖性。
4. **低优先级：重新堆叠 PSE/PCDC/CPC。** 退化识别、空间特征校正和一致性均有公开近邻；本项目尚无其超越 B1、普通代价敏感选择及常数动作的证据。G2/G3 目标信息可逆等价。投稿前仍需更新六篇近邻以外的 learning-to-defer、action-value 与变化检测文献检索。

## 已启动的独立数据候选预审：武汉大学建筑变化数据

- 官方[WHU Building Dataset 页面](https://gpcv.whu.edu.cn/data/building_dataset.html)提供 `Building change detection dataset_add.zip` 链接。2026-09-28 的只读 HTTP HEAD 返回 5,838,920,506 字节、支持 Range；仅以 Range 读取 ZIP 目录和少量样本，没有下载完整数据、训练或评估模型。
- 远程 ZIP 目录有 7,898 项。2012/2016 两个时相各有 `train/image` 1,260 张及 `test/image` 690 张 512×512 TIFF，并各有同数量的单时相建筑标签；另有 train/test 整幅二值 `change_label.tif`、大幅影像、world files 与矢量文件。抽查的首张配对影像为 RGB 512×512。**变化标签目前只确认整幅 train/test 文件存在，尚未证明其逐块裁切可与两时相影像精确对应。**
- Train 与 test world files 均为 0.2 m 像元；2012/2016 的起始坐标存在约 0.05 m 的时相差，change-label 亦有亚像素偏差，需用地理变换、像素对齐和人工可视化审查。官方 train/test 是相邻大图区域，并非多城市地理独立样本；同一大图的 1,260/690 个 tile 不可当作独立来源单位。
- 官方页面没有找到明确许可文字；远程 ZIP 目录也未列出 LICENSE、README、PDF 或 TXT 说明。网页可下载不等于已经核实再分发、模型训练或投稿的使用权。当前本机 `E:/thesis/datasets` 的完整数据仅有原 LEVIR-CD；候选目录中 9,220,096 字节的 `.partial` 是中止的慢速下载，**不是可用数据集**。完整下载需在许可和数据适配审查后再做。

### 候选准入条件

1. 找到官方明确的学术使用与成果发布条件，记录原文 URL、访问日期和引用要求；若仍不清楚，联系发布方或另选来源。不能仅凭第三方镜像自填许可。
2. 用独立的数据清单记录两时相、变化标签、年份、像元尺寸、坐标系、区域边界、来源和文件哈希；逐块验证配对、标签取值、配准及可辨识性。检查与现有各切分的编码/解码重复，并尽可能核查地理重合。
3. 以地理块/原始幅面划分新的 fit、calibration、validation 与 sealed holdout；相邻块加缓冲。若候选只有一个相邻地区，就明确其内部 holdout 不能证明跨地理泛化，并寻找第二个真正独立来源。
4. 在首个新 holdout 推理前冻结：数据许可和切分、新输入/标签协议、B1 迁移或从头训练规则、干预验收、动作集合、负对照、主指标、clean/召回/误伤门、源级不确定性、预算和停止规则。

[EPFL-ECEO 官方 Hugging Face 数据卡](https://huggingface.co/datasets/EPFL-ECEO/HRSCD_clean)标为 MIT，说明有法国 Rennes 与 Caen 两地的 291 个双时相影像对、二值变化标注，0.5 m 分辨率；其压缩包约 60.25 GB。数据卡说明标签修订可能仍漏掉变化，且官方精简样本曾由 Caen 训练模型筛查 Rennes 后再划分。若选择此集，应优先审查原始影像与 BD TOPO® 派生标注的具体权利，并用未经该模型筛选的来源和新的空间切分，避免把官方精简选择过程当成无偏独立测试。规模与读取成本远高于 WHU 候选；当前仅核对数据卡、HEAD 与远程 ZIP 尾部，未下载或运行实验。

## 加快节奏的执行顺序

1. **并行完成无需 GPU 的工作：**数据许可/来源核查、ZIP/影像/标签/地理审计脚本设计、论文稿独立复核及新的协议草稿。尽量复用现有模型、B1 和守卫代码；每项协议变动单独记录，不混称旧结果的复现。
2. **有合格新数据后先做便宜的证伪：**只在新训练部分抽样生成实际 no-op/固定/局部动作结果，检查可行动余量、误伤与可预测性；在独立新 validation 设置一次性门。若固定 B1 基线已充分解决问题或局部动作无净余量，则停止机制路线。
3. **仅门通过后训练正式模型：**先同预算 B1 与普通代价敏感/局部对照，再考虑特征校正；固定若干独立 seed、源级区间、模型/标签生成成本和温度守卫。新 holdout 在所有设置封存后只评一次。
