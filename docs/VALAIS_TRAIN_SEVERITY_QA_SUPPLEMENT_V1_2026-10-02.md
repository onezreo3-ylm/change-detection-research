# Valais train-only 扰动视觉 QA：方向均衡补充批

日期：2026-10-02。首批[候选 QA](../runs/valais_train_severity_qa_candidate_v1_20261002/train_visual_qa.json)的八行按正类/空标签交替；已有联系表生成器对两方向算子按行奇偶分配方向，因此正类只覆盖偶数行方向。该批全部720个实例与数值不变量仍有效，但不能据此判断正类目标在反向亮度/Gamma/对比度下的可辨认性。

本[补充配置](../configs/valais_train_severity_qa_supplement_v1_20261002.yaml)固定另一组四张正类、四张空标签 **Sion train** 影像，排除首批所有来源文件名；按独立 seed810208 的哈希排序选取。行顺序固定为 `正、空、正、空、空、正、空、正`，使两类各有两个偶数行和两个奇数行。global/local 两种预览中的目标时相也随行轮转。算子及五级**候选**强度直接绑定首批原始 LEVIR 候选数值，绝不从 Sierre/Martigny 分数调参。

补充批再生成720个实例和18张联系表。只读选中训练文件、原 baseline checkpoint 元数据、原候选与首批 QA 报告；不运行模型、不读 val/test 影像或标签。标签仅用于预先分层取样及事后可辨认性检查；注入 alpha 不读标签。两批合计每类样例在双向算子的方向上均衡，但仍只是16张训练样例，不代表所有 Valais 图像都可观测。

若强度或局部边界不可接受，应另立参数版本并只依据 train-only QA 调整；两批原产物保留，不能改名为已接受基准。B1 长训和 val 扰动评分仍须在候选参数、清单与协议冻结后开展。
