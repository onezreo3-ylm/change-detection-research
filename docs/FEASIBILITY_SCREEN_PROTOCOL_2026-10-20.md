# P1之后的有限可行性筛查（2026-10-20）

授权：用户在“先定位普通训练问题，再作有停止条件的小规模筛查”的建议后明确说“好，开始执行”。
本批执行保存结果归因、train-only BN统计干预和一次R5真实batch工程更新。不是恢复已完成训练，
不是P2方法效果实验，不恢复旧90分钟托管；本批结束保存报告。全部新产物使用独立目录。

## 在预测前固定的范围

- 保持原共享ResNet-18/绝对差FPN、FP32/CUDA、seed42、输入、loss和0.5阈值。
- 对原B0-E/C-S/A-S的100轮history与已保存clean-val逐源计数作描述性归因。
  只读已有val结果；不再推理val，不访问Martigny或旧LEVIR test。
  面积层固定0、1–64、65–256、257–1024、1025–4096、>4096；不据分数选层。
- 原P0的64个Sion train样本作为唯一BN诊断probe，保留16正/48空富集组成。
  它们都属于训练数据，且曾参与P0开发，不能称独立泛化/确认样本。
- 从已有11025个train源名中排除probe，以SHA256([固定tag,2026102001,源名])排序。
  uniform取最前256个；stratified以同一排序分别取64正/192空，每batch一正三空。
  两臂可重叠，校准与probe绝不重叠；这里只是源名不重叠，没有空间独立性保证。
  同臂源名/次序对所有checkpoint相同。使用旧label报告只为固定组成，不以预测选样。
- 每模型依次original、uniform_clean、stratified_clean。两校准臂都从其原checkpoint恢复，
  只reset BN running_mean/running_var/num_batches_tracked，momentum=None累计64次等大batch。
  每batch4个source，以clean+clean共8 pair views、双时相一次拼接更新BN。
  其余模块eval、全程no_grad；BN affine、其他参数和非BN缓冲必须逐位不变。
  每臂后eval；不互换不同模型的BN统计，不使用probe或val更新统计。
  累计的是batch内方差均值，不称全数据精确方差；深层统计依赖上游batch统计。
- 每臂在probe上单源FP32 eval，记录逐源计数、相对原臂的错误交换、logit均值/RMS/标准差，
  各模型首源每臂做重复/时相交换检查。original须精确复现原P0/残余clean逐源计数。
  总计576个主probe预测、18个额外自检；384个校准forward、3072校准pair views。
- 单次BN诊断上限1小时，GPU身份与原P0一致、>=85°C立即停止，数值/身份失败保留现场。
  不自动重试、不追加样本、不据结果选校准量/阈值/权重。不导出校准后的checkpoint。

## R5工程pilot

在诊断完整且无数据/数值身份失败后，允许独立一次、一个source batch的工程更新。
它不要求BN干预产生收益，也不用于方法准入；其问题只是原设备是否能承载预定五view计算。
使用原P0按既有顺序首个正源与首三个空源，以及它们已经封存的gamma L3四格，
不重抽u/v、不选择大分差样本。clean/uu/uv/vu/vv共20 pair views一次联合forward/BN更新。
监督权重1/2、四格各1/8；AdamW、学习率、梯度裁剪均沿用原配置。
从原seed42随机初始化，并精确核对旧initial tensor SHA256；不在旧best/last上续训。
只做1次反向/优化器更新，上限600秒；检查FP32、有限loss/梯度/参数、每层BN仅更新一次，
记录显存峰值与一次更新耗时。不评分、不选超参数、不保存可用于研究评分的权重。
OOM或温度失败即记录不可行，不降batch/精度、不拆BN、不换设备、不循环重试。
工程1步不说明整轮稳定性，也不作可靠吞吐/总训练时长估计。

## 解释与停止条件

采样曝光、train/val曲线、面积归因、BN反事实分别报告。改变统计的敏感性不等于
它造成原训练退化；校准损害也不等于BN无关。两臂都从头校准，控制reset/小样本效应；
保留B0-E普通模型对照，不只显示C-S/A-S的有利结果。
train上的恢复不允许替代clean-val保护门，也不按probe分数部署BN方案。
保存记录中a/b/i与损害的关联仅描述，不把重复像素/条件当独立样本或作因果/显著性声明。

正式R5/K5/M5/W5多轮训练仍未准入。未来必须另封同source、同五view、同更新/联合BN预算、
有限候选、保护门、近邻比较及机制否定控制。Hessian/一致性/DRO不换名主张原创。
若普通控制消除残余或候选仅压低好组/整体logit，结束混合响应特有贡献主张。
本次诊断无法补齐这些门时，保存报告，维持正式训练暂停，提出由证据支持的下一小步。

旧C-S95/A-S97至少1100步及其他未知精确废弃步数继续披露；本次smoke/BN干预/pilot
作为额外物理计算单列，不能并入旧匹配有效训练预算。
