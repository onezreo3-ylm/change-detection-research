# 新版实验主线：公开近邻复核

复核日期：2026-09-12。范围：六篇指定的公开论文/可读预印本，核对其方法、
训练目标与推理信息。本文是新版方案的 Step 1 文档产物，不是实验结果、
代码复现或“首次提出”的证明。旧版 `NOVELTY_REVIEW_2026-09-11.md` 保留为历史记录。

## 结论

新版主线可以继续做低成本证伪，但应定位为一个**待验证的决策问题**：
对固定检测器和实际可执行的校正动作，学习什么时候校正有益、什么时候有害，
并检验“扰动下收益 + 干净输入代价”的配对监督是否改善受约束决策。
PSE 仅作诊断，不以 MoE、退化识别或“校正伪变化”本身主张创新。

六篇近邻已经分别覆盖退化条件路由、显式伪变化补偿、空间残差门控、
扰动一致性及基于分支对错的选择。尤其不能把“预测是否值得修正”或
“允许保留原预测”当成空白。下面的机制是原文证据；后文的定位与对照要求是
本项目据此作出的研究判断。

两个不能忽略的区别：CSD-Net 的 Base 不依赖其可选基础模型扩展；
DeferredSeg 的 System 分数不是没有专家参与的自动分割分数。
因此，不能因前者有 MLLM/SAM 而排除它，也不能把后者的专家输出免费移植成
本项目的自动校正能力。见各表所引原文。

原文细节仍有待复现时澄清之处：SLER-IR §3.2 描述软路由使各专家获得梯度，
§4.1 又写到屏蔽非最大概率分支梯度；GTPC-SSCD 文本称选择困难样本，
式7 的实际条件是 `IoU >= median`。本报告不替作者修正这些描述，
也不以未经代码核实的梯度或困难度方向作贡献判断。

## 3. 对本项目定位的影响（研究判断）

| 已有邻近方向 | 不能作为独立新意的说法 | 新版方案须额外证明的内容 |
| --- | --- | --- |
| UniRestorer / SLER-IR：退化表征指导专家 | “先识别退化，再选择处理方式” | 不依赖退化类型标签，直接学习**固定动作的任务收益/代价**，且胜过同信息普通门控 |
| CSD-Net / PhyUnfold-Net：显式去除成像干扰 | “分离伪变化与真变化”“加入局部校正门” | 何时不应校正的决策证据；减少误报不能靠牺牲真变化召回 |
| GTPC-SSCD：扰动一致性和训练门控 | “有扰动、有门控、有一致性” | B1 增广和 B2 普通一致性之后仍有稳定、可重复缺口 |
| DeferredSeg：依据分支正确性学习保留/转交 | “根据实际效果学习是否干预”“加入不操作选项” | 自动可执行的同一校正动作，在 clean/perturbed 配对上的收益结构与伤害约束是否有增量价值 |

这些是相对于所核对六篇方法的**候选区别**，不是排他性新颖性结论。
损失差、条件收益和风险约束本身也不能仅靠重新命名变成创新。
若后续决定以动作收益估计作为论文核心，还需围绕 learning-to-defer /
cost-sensitive selection / conditional action value 作针对性公开文献复核。

## 4. 新版目标必须按实际动作定义

令 `x=(I1,I2)`，`Tx` 为保持语义的非几何扰动后输入，`y` 为同一变化标签。
固定检测器、校正器权重、动作和评估态；`L0(z)` 是不校正时的任务损失，
`L1(z)` 是**实际运行完整 tile 校正动作并重新前向**后的同一种任务损失：

```text
uT = L0(Tx) - L1(Tx)
u0 = L0(x)  - L1(x)
a  = uT - u0
```

`uT>0` 才表示该动作在扰动输入上降低损失；`u0<0` 表示对干净输入有害。
`a>0` 只表示扰动条件下的相对增益更大，不保证 `uT>0`，也不保证 clean 安全。
例如 `uT=-1, u0=-2` 时 `a=1`，但两种输入都被修坏。

`a` 是在指定合成扰动、动作和损失下的差分对比量，不能直接称为对真实世界
退化的已识别因果效应。标签不变也不意味着严重模糊/遮蔽后目标仍可观测。

G2 预测 `(uT,u0)`；G3 预测 `(uT,a)`。两者存在可逆变换：

```text
a = uT-u0                 u0 = uT-a
```

因此它们包含相同目标信息。G3 若更好，可能是参数化、归一化、损失尺度或优化
差异，不能声称多获得了一种信息。推理只能使用当前观测双时相输入及其可计算
特征/预测，不能输入配对干净图、真值标签或生成器的真实类型、强度和掩膜。

## 5. 必须保留的强对照与失败条件

1. **先 B1、B2，后校正决策。** 与既有 clean baseline 保持数据、初始化、
   切片、预处理、阈值、checkpoint 规则不变；B1 为增广，B2 为相同曝光的
   增广加普通一致性。记录实际前向数/更新数和训练成本，不把额外训练当结构收益。

2. **动作收益先存在，再训练门。** 在预定动作集合上保留“不校正”和
   “始终校正”对照，核查收益/伤害是否可区分；冻结检测器与校正器后再产生
   门控标签。若校正器几乎总是有害，或者始终校正已充分有效，应先否定或简化门控。

3. **G2/G3 公平性是主检验。** 使用完全相同输入、容量、动作集合、训练样本、
   优化预算、预测 `uT` 分支及 clean 伤害限制。目标标准化、两分量权重、阈值
   校准方法必须记录；通过配套尺度/损失对照区分“目标信息”与“训练参数化”。
   还须有同容量普通门控/直接收益预测对照，不只比较有门和无门。

4. **动作与标签粒度一致。** whole-tile 动作标签必须来自实际 whole-tile
   前向；不能按像素分别挑最好输出再拼出可部署的“校正结果”。clean 和
   perturbed 分支使用同一动作、同一损失定义与相同聚合规则。

5. **杜绝 actor/gate 数据泄漏。** 最新方案的 356/89 原始训练影像对划分用于
   actor/gate；检测器和校正器都只在356对actor子集训练。划分单位必须是原始
   影像对，不能把同源 tile 或扰动副本分到两边。原 val/test 64/128 对不变；
   标签生成、校准及 checkpoint 选择的职责单独记录。旧全445训练checkpoint
   不能冒充未见过gate子集的检测器；全训练集利用留到单列的交叉拟合等后续协议。

6. **相同伤害约束，完整报告取舍。** 比较匹配 clean 伤害限制或匹配校正比例
   下的收益、覆盖率与决策后悔值；同时报告 clean/perturbed pooled F1、IoU、
   真实变化 Recall、未变化区误报、负收益比例与尾部伤害。预测 `u0` 不是安全证明，
   必须用独立实际执行结果检查。所有阈值只用允许的验证数据冻结。

7. **样本外与成本。** 多种子、按原始影像对重采样区间；检查复合/未见扰动与
   A/B 交换，但不能用测试挑动作或挑门限。把额外特征、校正分支前向和标签
   生成成本计入；若门先运行校正器才能作决定，不宣称跳过了该计算。

若 G3 不稳定优于同信息 G2，或只有突破相同 clean 伤害限制才能提升鲁棒分数，
就不支持“配对差分参数化带来独立方法收益”的主张。
若 B2 已消除主要缺口，应允许停止增加校正器，而不是继续堆模块。
