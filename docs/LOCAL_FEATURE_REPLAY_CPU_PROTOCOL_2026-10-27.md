# 新机制候选：局部特征动作的参考归一化重放

2026-10-27。用户优先新方法；本批只准入独立CPU合成机制原型，不开启真实训练/推理，
不改原模型、原GN、活动B0-E源、配置或冻结分析。它尚未通过方法新颖性和效果门。

问题：局部feature residual即使只写入一个区域，后续GroupNorm的均值/方差也依赖全空间，
可能使区域外输出改变。此前窗口研究同时改变上下文与统计，未识别此机制；其配对大窗口
训练失败保持原结论。这里固定窗口和全部权重，只干预局部feature及统计读取路径。

候选操作：先对**当前观测双时相**运行无动作参考分支，缓存每个decoder GN的输入z0、
实际输出y0及每样本/组的方差。动作分支不重新用自己的统计归一化，而计算

`y1 = y0 + gamma * (z1-z0) / sqrt(var(z0)+eps)`。

这是借用同一观测输入的无动作分支，不使用理想clean图、真值或测试标签。差分写法保留
零动作的逐位恒等，并避免手工重算参考GN造成的全局舍入差。参考缓存detach；decoder权重、
GN仿射和BN均固定。先只验证FP32 CPU；不声称已有FP16/CUDA数值、梯度或资源准入。

在计算图仅含局部卷积、点操作、最近邻上采样且全部非局部GN都这样重放的条件下，
可由逐层支持传播证明：局部输入差异的卷积依赖支持以外，输出与参考一致。
此性质不是任务改善、安全或新颖性证明；原ResNet18/FPN的六个decoder GN全部覆盖才可检验。
prototype必须处理缓存身份、形状/dtype/device、非有限值、缺失/重复调用及异常后hook清理。

必要合成对照：原GN局部动作、仅最后GN重放、全部六层重放、原动作加普通输出支持掩膜。
最后一项也能令区域外不变，故不能只凭“不影响区域外”宣称方法增量。要求零动作精确重放、
区域内存在非零动作、模型参数/缓冲不变、梯度能通过动作且不产生GN的跨位置耦合。
使用原FPN64/8组的显式随机权重和合成多尺度features，仅作工程检查，不替代真实checkpoint。

RAIN的区域统计、AdaIN等统计迁移、GN分块近邻及激活/统计借用均必须继续排重。
当前不声称新GN算法、首个局部校正或普适无伤害保证。若现成区域统计或普通输出掩膜
已解释作用，则定位为控制/机制诊断，继续筛选有实质差异的方法。

真实train-only机制探针和新adapter拟合需要另冻完整协议：当前两行控制及其45条件完成后，
核对实际共享余额、原checkpoint身份、匹配普通对照、样本/seed、clean/Recall/FPR门、成本和
停止条件。不得通过缩短现有控制、重开旧test、追调失败参数或扩展48小时上限腾预算。
