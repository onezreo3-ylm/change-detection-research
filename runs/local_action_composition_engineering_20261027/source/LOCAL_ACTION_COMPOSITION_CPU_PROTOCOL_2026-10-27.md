# 可组合空间特征动作：CPU证伪检查

2026-10-27。参考统计公式与TIN已有同类机制，不能作为新原理。此检查仅研究其是否能
支持更具体的“组合动作代价可由单动作预测”的方法候选，不更改旧科研主张。

仅用原FPN64/8组、固定随机权重、CPU FP32及合成features/二值labels。无checkpoint、
原影像/标签、原val/test/Martigny访问，不开GPU，不更新优化器。旧统计重放源码、首个
原型和结果保持。超参数冻结在local_action_composition_cpu_20261027.yaml。

在stage2固定两个3×3区域，分别构造动作A/B，预先计算两者卷积影响支持并要求不相交。
action residual在基准features上一次生成，不依赖已选择的动作集合；所有分支使用相同
基准参考和全部权重。比较普通GN、普通GN联合动作后加输出支持掩膜、全部GN参考统计重放。
每个分支实际计算base、A、B、A∪B；不以相加后的输出冒充联合前向。

检验：联合输出与按各支持拼合的单动作输出逐位一致；联合混淆计数是否等于
`counts0+(countsA-counts0)+(countsB-counts0)`；区域外保持、零动作恒等、区域内
非零作用、模型参数/缓冲及hook清理。普通掩膜同样保持区域外，但不假设其组合性质。
标签仅用于合成整数算术检查，不产生方法F1或优越性结果。

为让固定0.5阈值检查覆盖实际标签翻转，合成classifier bias在所有比较之前统一减去一次
基准logit中位数；这是显式的工程fixture构造，所有分支共用，不是科研checkpoint调参。
失败即记录；不修改seed、振幅、区域或阈值追求预期结果。浮点输出检查区分数学命题与
逐位实现，不把小误差隐去；若只在容差内成立，必须如实报告，不能降为像素F1近似当恒等。

通过只支持准备真实train-only机制探针，不证明代价可从输入估计、不证明新颖性、安全或
泛化，也不构成正式方法训练准入。重叠影响支持、attention、train-mode BN或不同参考不在
可加性结论内。当前两行控制及固定评价完成前不启动任何新GPU任务，原48小时上限保持。
